# Interactive Resume — Mehmet Michael Ugurlu

A responsive, dependency-free GitHub Pages site featuring clickable resume sections, a scripted resume Q&A assistant, and a recruiter call/meeting request form.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose `main` and `/ (root)`, then **Save**.
4. After the first deployment, the site will be available at `https://ugurlumNIA.github.io/interactive-resume/`.

## About the assistant and meeting requests

The assistant is a client-side scripted FAQ, not a generative AI service. It only responds with details currently confirmed on the page and directs recruiters to contact Michael when document contents are unavailable. The request form opens the visitor’s email app with a prefilled message; it does not send an email, place a call, or book a calendar slot. Michael’s email and LinkedIn are included; no phone number was present in the materials supplied.

The supplied PDFs arrived as raw PDF data without readable resume text. The page deliberately avoids inventing work history, education, skills, or credential status. Add verified resume details to `index.html` when available.
